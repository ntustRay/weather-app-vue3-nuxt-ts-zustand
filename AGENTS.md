# Working on the Nuxt weather and to-do demo

- Nuxt routes are in `pages/`. Keep weather presentation in `components/WeatherWidget.vue` and to-do state and actions in `composables/useTodoStore.ts`.
- Run `npm ci` and `npm run build`. Use `npm run dev` to verify the weather page and `/todo`.
- Keep browser-only behavior on the client and check both a fresh route load and navigation between routes when changing shared state.
